Panduan Penamaan File Foto (Sangat Mudah & Otomatis):
Cara 1: Otomatis dari Nomor Soal
  • 1 Foto per Soal: Beri nama file 1.jpg, 2.png, atau soal_1.jpg.
  • 2 atau 3 Foto per Soal: Beri nama 1_1.jpg, 1_2.jpg, 1_3.jpg (atau soal1_1.png, soal1_2.png).
  • Sistem otomatis memasangkannya ke Soal Nomor 1, 2, dst.
Cara 2: Menggunakan Kolom Gambar di Excel
  • Di template Excel kolom gambar, tuliskan nama filenya, misal: peta_dunia.png.
  • Jika 2-3 foto di 1 soal, pisahkan koma: diagram_sel.png, grafik.jpg.
  • Unggah file dengan nama yang sama, sistem langsung mencocokkannya ke baris soal itu.
